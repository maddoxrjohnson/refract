Project launcher · Frozen shatter, round 4

One scene, three quality levels

The gems now use a custom glass shader. It bends whatever sits behind each gem, including that gem's own lit core, splits the light into a rainbow at the edges, and catches sharp glints on each facet. Switch the quality level to compare how each one looks and what it costs.

Size = mass Tint = main language Blue halo = uncommitted work Pulsing amber edges = agent cut off

Low battery, older laptops

  • One refraction sample, no rainbow split
  • Background behind the glass drawn at half resolution
  • No glow, no depth of field
  • Standard resolution, up to 30 frames a second

Medium the default

  • Rainbow split at the edges (3 samples)
  • Soft facet glints
  • Glow (bloom) on bright edges and cores
  • 1.5× resolution, up to 30 frames a second

High desktop GPU

  • Smooth spectral dispersion (12 samples)
  • Bright star glints on every facet
  • Glow plus depth of field: near and far gems go soft
  • Full resolution, up to 60 frames a second

Sample data: every repo name, language, mass and status is made up to show each state. The 40-repo mode adds placeholder repos.

On every level, the app stops drawing when the window is hidden or in the tray. The numbers above the scene count frames actually drawn and the CPU time each one takes. GPU time isn't visible to a web page, so watch Task Manager's GPU column while switching levels for the real cost.
