# 17. The Banknote scene replaces Frozen shatter

Status: accepted (supersedes the look in spec §3.2 and the effects in §3.6)

**Context.** The first scene drew each repo as a rough glass gem with refraction, a rainbow split, bloom, glints, a lit core and coloured halos for status. In use it read as glittery and loud, with candy colours and wireframe edges, and the status halos competed with the gems themselves. Four rounds of prototypes (`docs/mockups/gem-studies.html`) tried quieter directions: an engraved gemmology plate, a blueprint, and hybrids of the two.

**Decision.** Repos are real cut stones (round, emerald, brilliant, oval, princess, cushion) drawn as banknote security engraving: fine wavy line-work per facet, a guilloche rosette printed on the sheet under each stone, a pale wash of the language's colour, on paper seen from about 56° above. Dark mode is gold ink on deep green, with the lines marking the lit facets as on scratchboard. Status uses the vocabulary of the print: a hand-drawn red ring for uncommitted changes, the rosette turning for an agent at work, red line-work for an agent waiting on you (see the amendment below), a chipped corner for a session stopped mid-task, stipple instead of lines for a repo not cloned. Red only ever means that something needs you. The opening keeps the burst of the old scene: stones and splinters fly out from the centre and settle on the sheet. Light and dark follow the Windows app mode, with a Light / Dark / System override in settings, and every panel moves to the same paper and ink.

**Consequences.** There is no refraction, so the two-pass render, the back texture, the post-processing library, bloom, depth of field and tone mapping all go; the only extra pass is multisampling on Medium and High through three's own composer. The quality levels no longer change the look, only resolution, multisampling, the number of splinters and the frame cap, so a drop to Low under GPU load is barely visible. Low still stops the slow turning, so an idle scene draws nothing while a game runs. Line spacing is set in CSS pixels, so the engraving keeps its weight at every resolution, but very low resolutions can make the finest lines shimmer as a stone turns. Colours are specified as exact sRGB values and checked against screenshots, because a lost colour-space conversion would wash the paper out.

**Amended 2026-10-31.** The waiting state was first a pale red wash over the stone, pulsing slowly. In use it was not alarming enough and looked like the tint of a Rust repo. A waiting stone now draws its line-work and facet edges in red, with bold edges and a band of extra weight running up it, knocks every 1.6 s, and sends red rings across the sheet. Low and reduced motion keep only the red line-work.
